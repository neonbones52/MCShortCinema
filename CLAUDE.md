# CinemaShort

Перед любой работой прочитай `HANDOFF.md`: там суть проекта, утверждённые решения, инструменты в `tools/`, грабли и статус тестов. Потом `shot_list.md` и `production_readiness.md`.

- Общение с пользователем на русском. Пользователь — сценарист и режиссёр, Claude делает всё остальное (кроме звука).
- Проверять факты на машине и в файлах игры (javap по джарнику 26.2), а не предполагать.
- Blender управляется через MCP `blender` (`.mcp.json`). Длинные рендеры только в фоновом `blender -b`.
- После изменений персонажей гонять `mc_character.coplanar_report`. Кватернионы в ключах держать с непрерывным знаком.
- Новое решение пользователя записывать в `HANDOFF.md` (и в `shot_list.md`, если касается кадров).
